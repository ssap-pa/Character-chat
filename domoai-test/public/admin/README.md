## 1. 개요

관리자 패널은 AI 캐릭터 챗 서비스의 모든 설정을 **코드 수정 없이** 웹 UI에서 변경할 수 있는 도구입니다.

| 기능 | 설명 |
|------|------|
| 캐릭터 정보 편집 | 이름, 소개, 프로필 이미지 |
| 대화 로직 편집 | 오프닝 메시지, 예시 대화, 시스템 프롬프트 |
| 상황 이미지 관리 | 트리거 키워드 기반 자동 이미지 표시 |
| DomoAI 이미지 생성 | 캐릭터 추가 이미지 / 애니메이션 생성 |
| API 키 설정 | Claude · DomoAI 키 런타임 적용 |
| 세션 관리 | 전체 대화 세션 초기화 |

### 기술 스택

- **프론트엔드**: 순수 HTML + CSS + Vanilla JS (프레임워크 없음)
- **파일 경로**: `public/admin/index.html` (단일 파일)
- **인증**: JWT (유효기간 24시간)
- **통신**: Fetch API → `server.js` REST API

## 2. 접근 방법 및 로그인

### 2-1. URL 접근

```
http://localhost:3000/admin          # 로컬 개발
https://your-domain.com/admin        # 배포 환경
```

### 2-2. 로그인

| 항목 | 기본값 | 변경 방법 |
|------|--------|-----------|
| 비밀번호 | `admin1234` | `.env` 파일에 `ADMIN_PASSWORD=새비밀번호` 설정 |

1. 관리자 비밀번호 입력 → **🔑 로그인** 클릭
2. 성공 시 JWT 토큰이 `localStorage.adminToken`에 저장됨
3. 이후 모든 API 요청에 `Authorization: Bearer <token>` 헤더 자동 첨부
4. 토큰은 **24시간** 유효 (만료 시 자동 로그아웃)

### 2-3. 비밀번호 변경 방법

**방법 A — `.env` 파일 수정 (권장)**
```env
ADMIN_PASSWORD=your_new_password
```
서버 재시작 후 적용됩니다.

**방법 B — `server.js` 직접 수정**
```js
const ADMIN_PASSWORD_HASH = bcrypt.hashSync(
  process.env.ADMIN_PASSWORD || 'admin1234', 10
);
```

## 4. 메뉴별 기능 상세

### 4.1 📊 대시보드

관리자 로그인 후 첫 화면입니다.

#### 통계 카드 (자동 갱신)

| 카드 | 데이터 출처 |
|------|------------|
| 캐릭터 이름 | `characterConfig.name` |
| 활성 세션 수 | 메모리 내 `sessions` 객체 키 수 |
| 상황 이미지 수 | `characterConfig.situationImages.length` |
| 게스트 토큰 한도 | `GUEST_TOKEN_LIMIT` (기본: 10) |
| 회원 토큰 한도 | `MEMBER_TOKEN_LIMIT` (기본: 100) |
| 프롬프트 길이 | 현재 시스템 프롬프트 문자 수 |

#### API 연결 상태 배지

- 🟢 **Claude ✓ 연결됨** — API 키가 설정되어 대화 가능
- 🟡 **Claude ✗ 미설정** — API 키 없음 (대화 불가)
- 🟢 **DomoAI ✓ 연결됨** — 이미지 생성 가능
- 🟡 **DomoAI ✗ 미설정** — 이미지 생성 불가

#### 빠른 작업 버튼

| 버튼 | 동작 |
|------|------|
| ① 기본 정보 | 해당 메뉴로 이동 |
| ③ 프롬프트 | 해당 메뉴로 이동 |
| ④ 상황 이미지 | 해당 메뉴로 이동 |
| 🎨 이미지 생성 | 해당 메뉴로 이동 |
| 🔄 세션 초기화 | 확인 후 전체 대화 세션 삭제 |

> ⚠️ **세션 초기화**는 현재 대화 중인 모든 사용자의 대화 히스토리를 메모리에서 제거합니다.  
> 파일로 저장된 회원 히스토리(`data/sessions/*.json`)는 유지됩니다.

### 4.2 ① 기본 정보

**API**: `POST /api/admin/character/basic`

캐릭터의 프로필 이미지와 기본 정보를 설정합니다.

#### 프로필 이미지

**방법 1 — 파일 업로드**
- 업로드 박스 클릭 → 파일 선택
- 지원 형식: JPG, PNG, GIF
- 최대 크기: **20 MB**
- 업로드된 이미지는 서버에 `base64`로 변환되어 메모리에 저장

**방법 2 — URL 입력**
```
https://example.com/character-image.jpg
```
URL 입력 후 **[적용]** 클릭 → 미리보기 표시

#### 기본 정보 필드

| 필드 | 설명 | 예시 |
|------|------|------|
| 캐릭터 이름 * | 채팅 헤더 및 랜딩 페이지에 표시 | `도하준` |
| 한 줄 소개 | 캐릭터 이름 아래 표시되는 소개 문구 | `그림자 군단의 군주` |

> **저장** 클릭 시 전체 세션이 초기화됩니다 (새 설정 즉시 반영).

### 4.3 ② 인트로 & 예시 대화

**API**: `POST /api/admin/character/intro`

#### 오프닝 메시지

대화 시작 시 캐릭터가 처음 건네는 말입니다.

**작성 형식** (권장):
```
*[나레이션 — 3인칭 상황 묘사. 2~3문장.]*

"[캐릭터 대사.]"
```

실제 예시:
```
늦은 밤, 게이트 근처의 공기가 차갑게 가라앉아 있다.

도하준은 멀리서 너를 발견하고 걸음을 멈춘다.

"이 시간에 혼자 나온 거야?"
```

- `*기울임*` 형식 → 나레이션으로 분리 렌더링
- `"큰따옴표"` 형식 → 대사 말풍선으로 렌더링

#### 예시 대화

AI가 학습 맥락으로 사용하는 대화 예시 목록입니다.

| 필드 | 설명 |
|------|------|
| 사용자 입력 | 유저가 할 법한 말 |
| 캐릭터 응답 | 해당 입력에 대한 이상적인 응답 |

[＋ 추가] 버튼으로 새 예시를 추가하고, 각 예시의 [✕] 버튼으로 삭제할 수 있습니다.

> ℹ️ 예시 대화는 현재 시스템 프롬프트에 직접 주입되지 않습니다.  
> 서버는 이 데이터를 저장하며, 향후 few-shot 방식 프롬프트 주입에 활용할 수 있습니다.

#### 플레이 가이드

사용자 화면 채팅 상단에 표시되는 안내 문구입니다.

```
반말로 편하게 말을 걸어보세요. 그는 말수가 적지만, 당신의 감정 변화를 놓치지 않아요.
```

### 4.4 ③ 캐릭터 프롬프트

**API**: `POST /api/admin/character/prompt`

Claude/GPT에 전달되는 **시스템 프롬프트**를 직접 편집합니다.

#### 특수 변수

| 변수 | 치환 내용 | 비고 |
|------|-----------|------|
| `{{USER_NAME}}` | 사용자가 설정한 호칭 | 미설정 시 `너`로 대체 |

#### 자동 추가되는 내용

**상황 이미지**가 등록되어 있으면, 저장된 프롬프트 뒤에 다음 내용이 **런타임에 자동 추가**됩니다:

```
[이미지 표시 규칙]
답변에 아래 상황이 해당되면 반드시 응답 맨 끝에 <<IMAGE:상황ID>> 태그를 추가하세요:
- 상황 "미소": <<IMAGE:abc123>>
- 상황 "화남": <<IMAGE:def456>>
```

이 규칙은 서버의 `buildSystemPrompt()` 함수에서 동적으로 생성됩니다.

#### 권장 프롬프트 구조

```
너는 [캐릭터 이름]이다.

[캐릭터 기본 설명 1~2문장]

===핵심 규칙===
1. [규칙 1]
2. [규칙 2]
...

===출력 형식 (반드시 준수)===
응답마다 정확히 2세트.

*[상황묘사: 3인칭. 2~3문장.]*
"[짧은 대사.]"

*[이어지는 장면. 2~3문장.]*
"[짧은 대사.]"

===금지 사항===
- [금지 항목 1]
- [금지 항목 2]

호칭: {{USER_NAME}} 으로 부른다. 설정 없으면 "너"로 부른다.
```

> 우측 하단에 실시간 **문자 수 카운터**가 표시됩니다.  
> 프롬프트가 길수록 API 비용이 증가하므로 핵심 규칙만 유지하는 것을 권장합니다.

### 4.5 ④ 상황 이미지 라이브러리

**API**:
- `POST /api/admin/character/situation` — 추가
- `PUT /api/admin/character/situation/:id` — 수정
- `DELETE /api/admin/character/situation/:id` — 삭제

#### 동작 원리

```
사용자 메시지 전송
       ↓
Claude 응답 생성
       ↓
parseResponse() — <<IMAGE:id>> 태그 감지
       ↓ 태그 미감지 시
트리거 키워드 텍스트 매칭 (contains)
       ↓
일치하는 상황 이미지가 있으면 채팅 창에 자동 표시
```

#### 새 상황 이미지 추가

| 필드 | 필수 | 설명 | 예시 |
|------|------|------|------|
| 트리거 키워드 | ✅ | 응답 텍스트에서 감지할 단어 | `웃`, `미소`, `눈물`, `화남` |
| 상황 설명 | — | 관리자용 메모 | `미소 짓는 표정` |
| 이미지 | — | 파일 업로드 또는 URL | JPG/PNG, 최대 20MB |

> **키워드 선택 팁**:  
> - 짧은 어근 사용 (`미소` → `미소짓다`, `미소를` 모두 매칭)  
> - 너무 일반적인 단어(`좋다`, `하다`)는 오탐 발생 위험

#### 기존 이미지 수정/삭제

등록된 카드에서:
- **[수정]** — 트리거, 설명, 이미지 변경 가능
- **[삭제]** — 확인 후 즉시 삭제

### 4.6 ⑤ 캐릭터 상세

**API**: `POST /api/admin/character/detail`

랜딩 페이지 캐릭터 소개 섹션에 표시되는 정보입니다.

#### 상세 설명

캐릭터의 배경 스토리, 성격, 특징을 자유롭게 서술합니다.

- 최대 **1,000자**
- 랜딩 페이지 소개 카드에 표시

#### 장르

| 값 | 표시명 |
|----|--------|
| `romance` | 로맨스 |
| `fantasy` | 판타지 |
| `action` | 액션 |
| `daily` | 일상 |
| `thriller` | 스릴러 |
| `sf` | SF |
| `historical` | 역사 |
| `secondary` | 2차 창작 |
| `etc` | 기타 |

#### 해시태그

Enter 또는 쉼표(`,`)로 태그를 추가합니다.

```
나혼자만레벨업, 도하준, 헌터, 냉담남, 보호본능
```

- 태그 클릭 → [✕] 버튼으로 개별 삭제
- 랜딩 페이지 히어로 섹션에 `#태그` 형식으로 표시

### 4.7 ⑥ 세계관 & 스펙

**API**: `POST /api/admin/character/lore`

랜딩 페이지 하단 섹션에 표시되는 세계관 설명과 스펙 정보입니다.

#### 세계관 설명

캐릭터가 속한 세계, 배경 스토리를 서술합니다.

- 최대 **1,500자**
- 세계관 설명이 입력된 경우에만 랜딩 페이지에 해당 섹션 표시

예시:
```
《나 혼자만 레벨업》의 세계관 — 헌터들이 실존하는 현대 한국.
전 세계에 갑자기 던전 게이트가 열리기 시작하면서...
```

#### 캐릭터 스펙

최대 **6개** 항목의 레이블:값 쌍으로 구성됩니다.

| 레이블 | 값 | 렌더링 결과 |
|--------|-----|------------|
| `등급` | `군주급 (S+)` | 랜딩 페이지 스펙 그리드에 카드 형태로 표시 |
| `신장` | `183cm` | |
| `소속` | `아라한 길드` | |
| `능력` | `그림자 지배 · 군주의 권능` | |

- [+ 스펙 추가] 버튼으로 행 추가
- 각 행의 [✕] 버튼으로 삭제
- **저장** 시 빈 레이블/값을 가진 항목은 자동 제외

### 4.8 🎨 DomoAI 이미지 생성

**API**: `POST /api/admin/generate-images`

> ⚠️ DomoAI는 **비디오 생성 API**입니다. `text2video` 엔드포인트를 사용하여 짧은 애니메이션 클립(4초)을 생성합니다.  
> DomoAI 크레딧이 소모됩니다. 크레딧 부족 시 생성이 실패합니다.

#### 기본 생성 프롬프트 설정

모든 이미지 생성에 공통으로 적용되는 기본 프롬프트입니다.

```
anime male character, tall dark haired man, cold expression, 
hunter outfit, dramatic lighting, high quality illustration
```

- `{{CHARACTER_NAME}}` 사용 시 캐릭터 이름으로 자동 치환
- 영어로 작성할 것을 권장 (DomoAI 영어 프롬프트 최적화)
- [💾 기본값 저장] 버튼으로 저장

#### 단일 이미지 생성

1. **상황 프롬프트** 입력 (기본 프롬프트에 추가됨)
   ```
   smiling gently, soft lighting, close-up portrait
   ```
2. [🎨 생성] 클릭 → 최대 **3분** 소요
3. 생성 완료 후:
   - 미리보기 표시 (이미지 또는 비디오)
   - [📚 상황 이미지로 등록] → 상황 이미지 라이브러리에 즉시 추가
   - [🔗 원본 열기] → 새 탭에서 원본 URL 열기

#### 다중 이미지 일괄 생성

여러 감정/상황의 이미지를 한 번에 생성합니다.

1. **프롬프트 목록** 입력 (줄당 하나)
   ```
   smiling gently, soft lighting
   looking away coldly, side profile
   reaching out hand, protective expression
   eyes closed, calm breathing
   surprised expression, slight blush
   ```
2. **생성 수** 선택 (1~5개, 목록의 앞에서부터 선택됨)
3. [🎨 일괄 생성] 클릭 → 순차 생성 (병렬 생성 시 크레딧 소모 증가)
4. 진행 상황 표시 (진행 바 + 상태 텍스트)
5. 갤러리에서 호버 시 [📚 등록] / [🔗 열기] 버튼 표시

#### 기존 이미지 → DomoAI 애니메이션 변환

상황 이미지 라이브러리에 등록된 정적 이미지를 애니메이션 클립으로 변환합니다.

- **API**: `POST /api/generate-media`
- 변환된 클립은 해당 상황 감지 시 채팅창에서 자동 재생

### 트리거 매칭 방식

서버는 두 가지 방식으로 이미지를 매칭합니다:

2. **텍스트 포함 검색**: 응답 텍스트에 트리거 키워드가 포함된 경우

시스템 프롬프트에 이미지 트리거 규칙이 자동 추가되므로, Claude는 대부분 명시적 태그를 사용합니다.

관리자 JWT 유효기간은 **24시간**으로 하드코딩되어 있습니다.

```js
// server.js, POST /api/admin/login 핸들러 내
const token = jwt.sign(
  { isAdmin: true },
  JWT_SECRET,
  { expiresIn: '24h' }  // ← '12h', '7d' 등으로 변경
);
```

## 9. 자주 묻는 질문 (FAQ)

### Q. 설정을 저장했는데 채팅에 반영이 안 돼요.

각 저장 API는 `clearSessions()`를 호출합니다. 하지만 이것은 메모리의 `sessions` 객체만 초기화합니다.  
사용자가 이미 열려 있는 채팅 페이지를 **새로고침**해야 새 설정이 반영됩니다.

---

### Q. 프로필 이미지가 표시되지 않아요.

1. 이미지 크기 확인: **최대 20MB**
2. 지원 형식 확인: JPG, PNG, GIF
3. URL 방식 사용 시: CORS 정책으로 인해 일부 외부 도메인 이미지가 차단될 수 있음
4. base64 업로드 방식 권장

---

### Q. DomoAI 생성이 계속 실패해요.

1. [🔑 API 키 설정]에서 DomoAI 키 확인
2. 대시보드에서 DomoAI 연결 상태 확인 (🟢여야 함)
3. DomoAI 계정의 **크레딧 잔액** 확인 ([platform.domoai.com](https://platform.domoai.com))
4. 프롬프트에 정책 위반 단어가 없는지 확인

---

### Q. 세션 초기화를 하면 회원 대화 기록이 삭제되나요?

아니요. **대시보드의 🔄 세션 초기화**는 서버 메모리의 `sessions` 객체만 초기화합니다.  
회원의 대화 파일 (`data/sessions/{userId}.json`)은 그대로 유지됩니다.  
다음 대화 시 파일에서 히스토리를 다시 로드합니다.

---

### Q. 관리자 토큰이 만료되면 어떻게 되나요?

API 응답으로 `401 Unauthorized`가 반환되면 프론트엔드는 자동으로 로그아웃 처리합니다.  
로그인 화면으로 돌아가서 다시 로그인하면 됩니다.

---

### Q. 상황 이미지 트리거가 작동하지 않아요.

1. **프롬프트 확인**: ③ 캐릭터 프롬프트에 이미지 트리거 규칙이 자동 추가되는지 확인  
   → 상황 이미지가 1개 이상 등록되어 있으면 자동 추가됩니다
2. **트리거 단어 확인**: Claude 응답에 실제로 해당 단어가 포함되는지 로그 확인
3. **대/소문자**: 한국어는 대소문자 없음, 영어 트리거는 소문자 권장

---

### Q. 관리자 비밀번호를 잊었어요.

`.env` 파일에서 `ADMIN_PASSWORD` 값을 확인하거나, 기본값(`admin1234`)으로 되어있을 수 있습니다.

만약 변경된 비밀번호를 모를 경우:
```bash
# server.js에서 직접 해시 재생성
node -e "const b = require('bcryptjs'); console.log(b.hashSync('새비밀번호', 10));"
```
출력된 해시를 `server.js`의 `ADMIN_PASSWORD_HASH` 변수에 직접 입력합니다.
