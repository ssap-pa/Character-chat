⚠️ DomoAI는 비디오 생성 API입니다. 짧은 애니메이션 클립을 생성하며, 캐릭터의 동적 표현 이미지로 활용합니다.
DomoAI API 크레딧이 필요합니다. 크레딧 부족 시 생성이 실패할 수 있습니다.
